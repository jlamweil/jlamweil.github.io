# Issue Tracker

**Type**: GitHub Issues
**Location**: https://github.com/jlamweil/jlamweil.github.io/issues
**CLI**: `gh issue`

## Workflow

- Issues are created and tracked on the GitHub issue tracker for this repository.
- The `gh` CLI is used to create, read, update, and close issues.
- Each issue should be triaged using the labels defined in `triage-labels.md`.
- Implementation-ready issues carry the `ready-for-agent` label.
